# Sahaba Reader

`index.html` файлын ашыңыз. Ешқандай build/npm қажет емес.

## Фонды ауыстыру
`assets/images/backgrounds/` ішінде `bg-01.jpg` ... `bg-10.jpg` бар. Өз суреттеріңізді дәл осы атаулармен ауыстырыңыз. Сайттың әр сахаба бетінде оң жақта **Оқу фоны** панелі бар — 1–10 батырмасын басқанда фон бірден өзгереді және таңдау браузерде сақталады.

Егер өз фотоңызды қойғаннан кейін ескі фон көрінсе: браузерде **Ctrl+F5** басыңыз (Mac: Cmd+Shift+R). Бұл кэшті жаңартады.

## Жаңа сахаба қосу
Тек `assets/js/data.js` файлын ашыңыз. `SAHABA` массивіндегі бір `{ ... }` объектіні көшіріп, соңына қойыңыз. `id`, `arabic`, `categories`, `kk`, `ru` мәндерін өзгертіңіз. HTML/CSS/App.js-ке тимеуіңізге болады.

## Негізгі файлдар
- `index.html` — қаңқа
- `assets/css/styles.css` — дизайн
- `assets/js/data.js` — **контентті осы жерден басқарасыз**
- `assets/js/app.js` — сайт логикасы
- `assets/images/backgrounds/` — 10 фон
- `assets/images/portraits/` — кейін портрет/иллюстрация керек болса
